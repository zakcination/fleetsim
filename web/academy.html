    Compare configurations

    Run a configuration for 10+ simulated minutes, pin it, change one knob, pin again. The best value per column turns green.

    Same core as the fleetsim Python package: the League of Robot Runners warehouse crop (72 × 99 cells, 2,920 pod slots, 19 stations), Poisson orders, full-errand space-time A* with a reservation table, three dispatch policies. The health model (battery drain, motor heat and wear, lift cycles, lidar and encoder faults, technicians) is a teaching model with made-up but plausible rates, not data from a real fleet. One tick = one second.
